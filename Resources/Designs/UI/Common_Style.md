# Common Style

## 개요

- **대상 플러그인**: `UniversalGameFramework`
- **버전**: v0.1.0
- **작성일**: 2026-05-17
- **설명**: `Common UI` 플러그인을 사용하여 구현된 위젯에서 사용되는 배경, 텍스트, 버튼 스타일 등을 정의한 문서입니다.

| 배경 스타일 | 역할 | 적용 대상 | 이미지 | 색조 | 그리기 방식 | 코너 반경 | 윤곽선 | 너비 | 설명 |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| **Background** | 기본 배경 | 메인 캔버스, 전체 화면 배경 | None | `#0F172A` | Rounded Box | 0.0 | 투명 | 0.0 | 깊이감 있고 모던한 다크 슬레이트 |
| **Card** | 카드 배경 | 팝업 창, 모달 카드, 다이얼로그 박스 내부 | None | `#0F172A` | Rounded Box | 6.0 | `#334155` | 1.5 | 시각적 격리를 유도하는 차분한 다크 네이비 |

| 텍스트 스타일 | 역할 | 적용 대상 | 폰트 패밀리 | 타입페이스 | 크기 | 문자 간격 | 컬러 | 설명 |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- |

| **Primary** | 강조 텍스트 | 기본 버튼 라벨, 강조 본문 | Roboto | Medium | 14 | 0.5 | `#FFFFFF` | 가장 중요한 정보 및 액션 유도 |
| **Secondary**| 기본 본문 | 일반 정보 텍스트, 보조 버튼 라벨 | Roboto | Medium | 14 | 0.5 | `#E2E8F0` | 편안하게 인지되는 밝은 화이트 그레이 |
